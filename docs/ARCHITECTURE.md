# Architecture and Experiment Flows

This document describes the public engineering boundary. It is deliberately more
conservative than the implementation: a component being present does not imply that an
end-to-end experiment has passed.

not call the Track B training path. Track A is derived from

independent authorship.

## Low-VRAM Launch Flow

```mermaid
flowchart TD
    Start["Select a status-labelled profile"] --> Provenance{"Pinned checkout<br/>clean and correct commit?"}
    Provenance -- "no" --> Reject["Refuse to start"]
    Provenance -- "yes" --> Profile{"Profile verified,<br/>or --allow-unverified?"}
    Profile -- "no" --> Reject
    Profile -- "yes" --> Cgroup{"Effective cgroup<br/><= 4 GiB?"}
    Cgroup -- "no" --> Reject
    Cgroup -- "yes" --> Swap{"Zero-Swap profile:<br/>memory.swap.max = 0?"}
    Swap -- "no" --> Reject
    Swap -- "yes" --> Run["Launch unmodified upstream training"]
    Run --> Monitor["Sample cgroup, process tree, GPU,<br/>and whole-system Swap"]
    Monitor --> Gate{"Stop condition or<br/>telemetry failure?"}
    Gate -- "no" --> Finish{"Training completed?"}
    Finish -- "no" --> Monitor
    Finish -- "yes" --> Checkpoint["Validate checkpoint on CPU"]
    Gate -- "yes" --> Stop["Terminate process group<br/>preserve artifacts"]
```

## Fail-Stop Protection Path

```mermaid
flowchart LR
    Input["replay / simulation / imagination"] --> Finite{"All values finite?"}
    Finite -- "no" --> Diagnostic["Preserve input, networks, optimizers,<br/>and RNG state"]
    Diagnostic --> Abort["Raise NumericalFailure<br/>before optimizer step"]
    Finite -- "yes" --> Backward["Original backward pass"]
    Backward --> Gradients{"Gradients finite?"}
    Gradients -- "no" --> Diagnostic
    Gradients -- "yes" --> Clip["Original gradient clipping"]
    Clip --> Optimizer{"Network and Adam state safe?"}
    Optimizer -- "no" --> Diagnostic
    Optimizer -- "yes" --> Step["Original optimizer step"]
```

The guards do not replace values, skip a batch, or relax configured thresholds. They fail
closed and preserve diagnostics for analysis.
